# Ayni (pinned copy)

This folder is a copy of the parts of [Ayni](https://github.com/peyrona/ayni) that Nayive uses so far: the base
(colours, light and dark, icons, texts), the buttons family (buttons, switches, ticks), the notifications family (toasts with Undo, progress)
and the language files. Nayive
takes Ayni one family of controls at a time, so only the families already moved are here.

Never edit these files here: change Ayni, run its tests (`node tests/run.mjs` there), then copy the files again.
