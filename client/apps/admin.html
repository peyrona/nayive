Admin account

First run: create the admin account. It is saved as soon as both fields are filled; then you'll be asked to sign in with it.

Forgot this password? An empty admin password does not ask for a new one, as it does for a user: it locks the admin out. To reset it, on the server edit store/config/server.json and, inside the "admin" block, set a temporary password in plain text ("password": "temp123"). Restart Nayive at once - it reads that file only when it starts, and may write the old one back before. Sign in with it (it is stored hashed from then on) and pick a real password here.

Web sites

Plain web sites served by this server, apart from Nayive. Each sub-folder of this folder is one site: cv/index.html opens at /cv/. A new sub-folder works at once. Only put pages you trust here: they share Nayive's address. Leave empty to serve no web sites.

The + button above the trash icons adds an empty row for a new user; its (×) drops the row again. Every change is saved on its own when you leave the field (or press Enter); a new user is created once it has a name. Changing a username renames the account: everything the person owns travels with it, but they are signed out and must sign in again with the new name. The trash icon deletes a user (after a confirmation) along with all their data. The small trash inside a password field removes that password at once: the user signs in with a blank one and must pick a new password.
